# 最後一眼：飛靶注意力拉鋸戰

一個適合射擊教練講習現場使用的繁體中文互動 Web App。玩家要從中央等待點判讀左右隨機出靶，快速轉移準星、追蹤飛行路徑，並在干擾與壓力下完成穩定擊發。四階段依序體驗 DAN、VAN／跳視轉移、壓力與 Quiet Eye 賽前程序。

## 四階段

1. 安靜基準：不預猜方向，等待左右隨機出靶。
2. 注意力拉鋸：辨認真飛靶與假飛靶／突發干擾。
3. 壓力射擊：在倒數與催促訊息下保留擊發判斷。
4. 程序重整：先做「吸氣、吐氣、鎖定」，再等待出靶。

結果頁呈現操作分數、穩定後擊發比例、干擾誤觸與「出靶至準星首次接近目標」的轉移時間。

## 開啟方式

可直接雙擊 `index.html`，或在此資料夾啟動靜態伺服器：

```bash
python3 -m http.server 4173
```

再開啟 `http://localhost:4173`。

## 教學邊界

遊戲以滑鼠、觸控或鍵盤操作模擬注意力轉移、追蹤與穩定準備歷程。遊戲中的「跳視轉移時間」是準星操作代理指標，未使用眼動儀，不能當作真實眼球跳視、Quiet Eye、神經功能、選手能力或醫療評估結果。
